# AI ChatGPT

ChatGPT 스타일의 AI 채팅 웹 애플리케이션을 만들기 위한 시작 프로젝트입니다.

## 목표

- 깔끔하고 반응형인 AI 채팅 인터페이스
- 대화 목록과 현재 대화 화면 제공
- 향후 OpenAI API 연동을 고려한 구조
- 데스크톱과 모바일 환경 대응

## 현재 구현

- 좌측 사이드바
- 새 대화 버튼
- 대화 목록 UI
- ChatGPT 스타일의 메인 채팅 영역
- 사용자/AI 메시지 카드
- 메시지 입력창과 전송 버튼
- 반응형 레이아웃

## 프로젝트 구조

```text
ai_chatgpt/
├── README.md
├── index.html
├── styles.css
└── app.js
```

## 실행

별도의 빌드 도구 없이 정적 HTML로 실행할 수 있습니다.

1. 저장소를 클론합니다.
2. `index.html`을 브라우저에서 엽니다.
3. 또는 VS Code의 Live Server 등을 사용합니다.
